# Double Pendulum Simulation
A simulation of a double pendulum I made whilst preparing for my Numerical
Analysis Exam which includes a few of the methods for solving ODEs.

Equations of motion for the pendulum were derived using Lagrangian mechanics
using SageMath to carry out the tedious algebra (since I can be very error prone in that regard!),
see the notebook in the root of the repository for more details in that regard.
